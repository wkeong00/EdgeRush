# 04 · TapTap 国际版上架

> 以下信息核对于 2026-10-23，来源是 TapTap 官方文档与 Google Play 要求。后台表单可能改版，**以你登录后看到的为准**。

## 一、账号

- 开发者中心：**https://developer.taptap.io/**（注意是 `.io`，不是国内的 `.cn`）
- 两种账号：
  - **Registered Developer**：只要 Tap.io 账号，可发布，无审核等待；
  - **Verified Developer**（个人身份证 / 企业营业执照）：审核约 2 个工作日，**才能用财务（收款）和 TDS 服务**。
- 想赚钱就必须过 Verified。**建议现在就去提交认证**，它和开发并行，别等到包做好了才卡在这里。

## 二、创建游戏

1. 后台 **Create Game** → 填英文名 **Edge Rush**（先在 TapTap 和 Google 搜一下有没有重名/商标冲突）。
2. 填包名 `com.yourstudio.edgerush`（**必须和你 APK 里的 applicationId 完全一致**，且上架后不能再改）。
3. 上传 APK。**TapTap 国际版只接受 APK，不接受 AAB**（这点和 Google Play 相反）。

## 三、素材清单（对照 2026 官方要求）

| 素材 | 规格 | 备注 |
| --- | --- | --- |
| 图标 | **512 × 512**，PNG/JPG | 主体放在安全区内，别贴边 |
| 截图 | ≥ 3 张（建议 5 张），**≥ 1280 × 720**，全部同尺寸，9:16 竖屏或 16:9 横屏 | 不能出现设备边框、其他商店评分、其他游戏 |
| 封面图 | **1920 × 1080**，重点内容在 **1760 × 920** 安全区 | 除游戏名外不要放文字 |
| 宣传图 | 1920 × 1080（可选，没有就用封面） | |
| 视频 | MP4 ≤ 1 GB，**≤ 60 秒**（20 秒最佳），≥ 1280 × 720 | 需要另配 **1256 × 706** 封面；视频对转化率帮助最大 |
| 简介 | 英文，无空行 | 别写「提现/领现金」 |
| 更新说明 | 英文 | |
| 隐私政策 | 一个可访问的 URL | 不一定是必填项，但广告 SDK 收集设备标识，写了更安全 |
| 年龄分级 | 按后台问卷填 | 含广告的游戏通常 12+ / Teen |

## 四、审核与发布

- 新游戏首次审核 **约 2 个工作日**；版本更新约 24 小时。
- 定时发布需要提前 **≥ 24 小时** 设置。
- 被拒最常见的原因：素材违规（带设备边框 / 出现别的游戏 / 现金诱导）、包签名是 debug、包名与后台不符、崩溃。

## 五、政策红线（广告相关）

TapTap 开发者协议明确允许游戏内广告，但禁止：

- 广告内容违法/敏感；
- **模仿系统通知/系统弹窗的广告**（诱导点击）；
- 游戏关闭或退到后台后仍在展示广告；
- **无法关闭的弹窗广告、悬浮广告**；
- 捆绑下载、强制安装。

本工程的做法：**只有玩家主动点击才播放激励视频，没有插屏、没有自动弹窗、广告可关闭、看完才发奖励**——完全符合。注意 Mock 广告里的 SKIP 按钮只是开发用，正式包不会出现。

## 六、签名 / MD5

- 上架**不需要**登记 MD5。TapTap 只要求 **不能用公开/debug 证书签名**（见 `02-安卓打包.md` 第 4 步）。
- 只有当你启用 **TapTap 登录**（TDS）时，才需要在 **Game Services → Application Configuration → Signature Certificate** 填 32 位 MD5（去掉冒号）。

## 七、TapSDK 要不要接？

**v1 不用。** 依据：开发者协议写明 TapSDK 属于可选服务，且它提供的是登录/内购/分析，**不含广告**。上架不需要它。

以后想加（例如「TapTap 登录 + 好友排行」）：

1. 后台启用 Game Services，拿到 Client ID / Client Token；
2. 按 `tapsdk integration.txt` 在 `Packages/manifest.json` 加 `com.taptap.sdk.core` 与 Newtonsoft / EDM；
3. 在 `GameApp.Awake()` 里初始化（务必用 `TapTapRegionType.Overseas`）；
4. 后台登记签名 MD5；
5. 混淆脚本里加 `-keep class com.taptap.**{*;}`。

## 八、上架前 12 项自检

- [ ] 包名改成自己的，且与后台一致
- [ ] APK 用 release keystore 签名（不是 debug）
- [ ] versionCode ≥ 1，每次更新 +1
- [ ] 真机跑通：开局、撞车、复活、结算、双倍、车库、签到、任务、设置
- [ ] 断网时游戏不崩
- [ ] 广告用正式 ID（不是 `3940256099942544` 测试 ID）
- [ ] 隐私政策 URL 可访问，并写进简介
- [ ] 512 图标、≥3 张 1280×720+ 截图、1920×1080 封面
- [ ] 20 秒宣传视频 + 1256×706 封面（强烈建议）
- [ ] 英文简介，无现金诱导词
- [ ] 目标 API 与后台要求一致（后台没写死；Google Play 自 2026-08-31 要求 **API 36**，用同一个包两边都能过更省事）
- [ ] 安装包 < 50 MB
