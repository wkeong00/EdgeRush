# v2.0 批次 A、B 实施与验收

日期：2026-10-28。基线为《优化方案 v2.0》，本次实现范围是稳定性、奖励、签到、屏幕布局、操作教学与输入。C 的交通验证、两道具、七款车精修，以及 D/E 的真实商业接入与发布继续单独验收。

## 已实现的代码

- 广告初始化和加载有异步边界、单飞请求、回调代际和有上限的重试。Mock 的成功、跳过、关闭、失败均有终态；奖励提交与关闭后的界面恢复分开。
- 全广告位共享 60 秒间隔。正式开局快照新手资格，前三个完成局的复活／翻倍入口隐藏，第四局开始才允许。广告显示期间不会接收跑局与返回键操作。
- Release 禁止静默回退 Mock；启用广告但缺真实 SDK、缺正式广告位 ID 或使用 Google 测试 publisher 时阻止构建。当前工程没有安装或验收真实广告 SDK。
- 奖励按来源和幂等键入账，结算基数与广告追加分开。新增存档字段、旧档迁移、备份回退与七日循环检查。
- 单安全区、顶部／底部锚定、共享钱包、任务滚动列表与独立奖励区、车库预览／购买分区、固定广告按钮与不可用原因。
- 独立操作教学：左变道、右变道、安全擦边。失败只重试当前步骤，可跳过、设置里可重播，不创建正式 RunSession。
- 一次手势最多变道一次；UI 触摸、取消、多指、暂停旧手势均清理。滑动越过阈值立即响应，抬手不再重复。
- 变道与保护使用有效玩法实时时钟，擦边慢镜头仅缩放世界；连击也用有效玩法时间。结算显示本局最高倍数。设置增加减弱震屏／闪光选项。补上世界相机缺失的 AudioListener，菜单隐藏局内车辆以避免重复预览。

## 固定的首轮参数

`Tuning.Version = v2-baseline-ab-1`。变道 0.12 秒，起始速度 8，每 10 秒加 1，最大 22；行间隔从 1.6 秒过渡到 0.55 秒，过渡 120 秒，开局宽松期 15 秒。擦边基础 10 分，最高 5 倍，连击宽限 5 秒、每 1.2 秒掉一级。此次未改皮肤价格、碰撞箱和交通图案。

时钟口径：`RunSummary.seconds` 为有效玩法时间，`worldSeconds` 为包含演出减速的世界模拟时间，`realSeconds` 为开局至结算的现实经过时间（包括暂停／广告）。金币 `coins` 为实际拾取及其结算基数，不含签到与任务。

## 可重复的检查入口

从项目根目录的上级运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File _tools/compilecheck.ps1 -Development
powershell -NoProfile -ExecutionPolicy Bypass -File _tools/compilecheck.ps1 -Editor
```

Unity 菜单：`EdgeRush/Checks/Gameplay Input and Clocks`、`EdgeRush/Checks/Ad Configuration and Callback Guards`，以及经济检查菜单。检查为实际逻辑断言，不代表触摸手感或商业 SDK 已验收。

自动画面验收入口：`EdgeRush.EditorTools.OptimizationVerification.RunBatch`，传 `-edgeRushVerification`。该模式使用项目 `Temp/VerificationSave`，禁用默认 PlayerPrefs 备份，避免覆盖玩家存档。使用 Unity 6000.6.7f1，运行真实 Play Mode，输出到 `docs/verification-ab/`。截图为实际界面渲染；HUD／复活／结算的数据含构造的验收样例，不能直接用作商店真实跑局素材。

覆盖 16:9、18:9、19.5:9、20:9，以及模拟顶部刘海／底部手势区的安全区域。每组捕获菜单、任务、车库、教学、HUD、复活、结算。模拟安全区与 Editor 截图不能代替 Android 真机。

## 验证结果

Unity 6000.6.7f1 实际编译与 Play Mode 通过，进程退出码 0，`verification-ab/result.txt` 为 PASS。

- 离线默认运行时、Development 运行时与 Editor 编译通过；Editor 保留原 `androidIsGame` 弃用警告。Unity 还提示现有运行时 UI 类型不参与序列化，以及 Development 条件宏弃用提醒；无编译错误或运行时异常。
- 输入／时钟 24 项、广告配置／回调守卫 9 项、经济／迁移／文件恢复 59 项，共 92 项基础断言通过。
- 真实 Play Mode 跑通：操作完成教学、正式开局、暂停冻结与恢复、拾取金币、障碍碰撞、广告复活、结算、广告翻倍。验证翻倍奖励在广告关闭前已保存，重复进入不会二次到账。
- Mock 成功、跳过、关闭、失败均关闭展示状态并仅回调一次；前三个完成局的广告资格在结算时仍保持关闭。
- 五组比例共 35 张截图；逐次检查 Screen 分辨率，抓图后等待实际渲染再切屏，避免异步截图错页。第 4 组用顶部 5%、底部 2.5% 的模拟安全区。画面文件见 [验收截图](verification-ab/README.md)。
- 存档检查覆盖旧档迁移、重复回执、7→8 天签到、断签、两次连续主档损坏，以及较新 PlayerPrefs／`.bak` 优先于旧有效主档。游戏验收使用隔离文件存档；备份选择检查仅使用随机测试 PlayerPrefs key 并在 finally 删除，没有改写真实 `edgerush.savedata`。

这些结果证明本批本地实现可编译且检查流程通过。触摸手感、实际刘海、发热／帧时间、Android 生命周期和真实 SDK 仍需对应设备与环境。
