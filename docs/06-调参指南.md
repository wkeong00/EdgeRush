# 06 · 调参指南（想改数值看这里）

所有可调数字都集中在这几个文件，改完直接 Play 就能看到效果。

## 1. 手感与难度 — `Assets/Scripts/Core/Layout.cs`（`Tuning` 类）

| 常量 | 当前值 | 含义 |
| --- | --- | --- |
| `SpeedStart` | 8 | 起始速度（世界单位/秒） |
| `SpeedPerTenSeconds` | 1 | 每 10 秒加速多少 |
| `SpeedMax` | 22 | 速度上限 |
| `RowIntervalStart` | 1.6 | 起始每行间隔（秒） |
| `RowIntervalMin` | 0.55 | 最小行间隔 |
| `RowIntervalRampSeconds` | 120 | 用多久从 1.6 压到 0.55 |
| `WarmupSeconds` | 15 | 热身期长度（每行只放 1 个障碍） |
| `LaneChangeTime` | 0.12 | 换道时长，越小越"神经" |
| `NearMissWindow` | 1.5 车长 | 擦边判定窗口，调大更容易触发 |
| `NearMissLaneTolerance` | 0.72 车道宽 | 擦边的横向容差 |
| `ComboStep` | 3 | 几次擦边升一级 |
| `ComboMax` | 5 | 倍数上限 |
| `ComboGraceSeconds` | 5 | 连击宽限（秒） |
| `ComboDecayEvery` | 1.2 | 宽限后每隔多久降一级 |
| `ReviveInvulnSeconds` | 2 | 复活无敌时间 |
| `ReviveSpeedFactor` | 0.8 | 复活后速度比例 |
| `ReviveAdOfferAfterRuns` | 3 | 前 N 局不弹复活 |
| `MetresPerTheme` | 500 | 多少米换一次主题 |

> 想让游戏更简单：`RowIntervalMin` 调大（0.7）、`SpeedMax` 调小（18）、`NearMissWindow` 调大。
> 想让擦边更爽：`NearMissBasePoints` 调大、`ComboStep` 调小（2）。

## 2. 图案库 — `Assets/Scripts/Gameplay/Patterns.cs`

图案就是字符串数组，`.` 空、`X` 随机障碍、`T` 卡车、`B` 路障、`M` 移动车：

```csharp
new Pattern { id = "my_pattern", difficulty = 2, rows = new[] { "XX.", "X.X", ".XX" } },
```

规则（代码会强制）：
- 一行最多 2 个障碍（写 `XXX` 也会被随机放开一条）；
- `PatternLibrary.IsSolvable` 会模拟玩家可达车道，不可解会被替换成单障碍；
- 难度 = 0 热身 / 1 普通 / 2 进阶 / 3 极限，按 `RunSession.MaxDifficulty` 放开。

## 3. 经济 — `Assets/Scripts/Systems/Progression.cs`

- `DailyRewards`：7 天签到金币数组。
- `QuestPool`：8 个任务（目标值 `target`、奖励 `reward`）；每天按日期种子抽 3 个，指标不重复。
- 车辆价格在 `Art/Palette.cs` 的 `Skins.All`（`price`）。
- 广告奖励：`Tuning.DailyAdMax`（每天几次）、`DailyAdCoins`（每次金币）、`SkinAdCount`（皮肤要几次）、`SkinAdRewardCoins`。

## 4. 视觉 — `Assets/Scripts/Art/`

| 想改什么 | 改哪里 |
| --- | --- |
| 主题配色（城市/隧道/沙漠） | `Palette.cs` → `ThemeDef` |
| 玩家车/障碍车/卡车外形 | `Art.cs` → `MakeCar()` / `Truck()` |
| 路障条纹、金币图案 | `Art.cs` → `Barrier()` / `Coin()` |
| 路面纹理、车道线、虚线长度 | `Art.cs` → `RoadTexture()`（`dashLen`、线宽、发光强度） |
| 界面颜色 | `Palette.cs` 顶部的 UI 颜色 |
| 图标 | `Art.cs` → `Icon*()` |
| 粒子数量/大小 | 调用处：`FxManager.Sparks/CoinBurst/Crash` |

## 5. 音效 — `Assets/Scripts/Audio/Synth.cs`

- `MusicLayer(0..3)`：0 贝斯、1 琶音、2 主旋律、3 打击。改 `BassRoots` / `ArpNotes` / `LeadNotes` 就是改和声走向（现在是 Am–F–C–G）。
- `BPM`（128）、`BeatsPerLoop`（16）。
- 音效：`SfxWhoosh / SfxCoin / ...`，参数是（起始频率、结束频率、时长、音量、波形、衰减）。
- 想换成真实音频：见 `05-已完成与待办.md` 的「想替换成真实美术/音乐」。

## 6. 广告频率 — `Assets/Scripts/Systems/Ads.cs` 与 `GameApp.cs`

- 广告位是否可用：`AdManager.Available(placement)`。
- 复活资格：`GameApp.CanOfferRevive`。
- 双倍资格：`GameApp.WatchDoubleCoins`（每局一次）。
- 每日广告：`Progression.DailyAdsLeft`。

## 7. 存档版本

改 `SaveData` 字段时**只增不删**，并给新字段默认值；`SaveSystem.Version` 加一，老档缺字段会自动用默认值 + `Sanitize()` 兜底。
