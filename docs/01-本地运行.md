# 01 · 本地打开与运行

## 一次性准备

1. **Unity 版本**：你装的是 `6000.6.7f1`（Unity 6.6）。打开时如果 Hub 提示版本不匹配，选「用已安装版本打开」即可；Unity 会自动升级工程。
2. **激活许可证**：如果你还没登录过 Unity Hub，第一次打开编辑器会要求登录 / 激活 Personal 许可证。这一步必须由你完成（我无法替你登录）。

## 打开

1. Unity Hub → **Add / 添加** → 选择 `EdgeRush` 文件夹（不是 `Assets`，是包含 `Assets`、`Packages`、`ProjectSettings` 的那一层）。
2. 首次导入约 1–3 分钟。导入结束后，编辑器会自动执行 `EdgeRushSetup`：
   - 设置公司名 / 产品名 / 包名 / 竖屏 / IL2CPP / ARM64 / minSdk 26；
   - 生成 `Assets/Scenes/Main.unity`（空场景）；
   - 把它加入 Build Settings。
   - 控制台应出现 `[EdgeRush] Project settings applied.`
3. 菜单 **EdgeRush → Apply Project Settings** 可随时重新执行；**EdgeRush → Rebuild Main Scene** 可重建场景。

## 运行

- 直接按 **Play**。即使当前是空场景也能跑，因为游戏由 `Bootstrap`（`RuntimeInitializeOnLoadMethod`）在运行时创建。
- 建议先把 Game 视图分辨率设成竖屏，例如 **1080 × 1920** 或设备模拟里的 iPhone/Android 竖屏，这样界面比例和手机上一致。

### 编辑器里的操作

| 操作 | 效果 |
| --- | --- |
| 点击屏幕左半边 / 右半边 | 向左 / 向右换道 |
| 鼠标左右拖拽（> 屏宽 4.5%） | 滑动换道 |
| `A` / `←`，`D` / `→` | 换道（桌面测试用） |
| `Esc` | 暂停 / 返回 |

## 你会看到什么

1. 主界面：EDGE RUSH、最高分、金币、当前车、PLAY、车库/每日/任务、设置。
2. PLAY → 快速 3-2-1 → 开始跑。速度每 10 秒 +1，上限 22；路面每 500 m 换主题（霓虹城市 → 隧道 → 沙漠黄昏）。
3. 贴着车变道会弹 `CLOSE!`，连击倍数上升，吃到金币有音效和粒子。
4. 撞车 → 白闪 + 震屏 + 碎片 → 5 秒复活弹窗（第 4 局起才会出现，符合文档「前 3 局不弹」）→ 结算页可看广告翻倍金币。

## 常见问题

**控制台报 `[Ui] No font available`**
极少见，说明内置字体 `LegacyRuntime.ttf` 不可用。把任意 .ttf 拖进 `Assets/Resources/`，然后在 `Assets/Scripts/UI/Ui.cs` 的 `InitFont()` 里加一行 `Font = Resources.Load<Font>("你的字体名");`。

**画面是黑的**
检查 Game 视图是否是「Free Aspect / 横屏」而相机在竖屏布局外——设成竖屏即可；另外确认 Console 没有异常。

**点了没反应**
Unity 6 新工程的 Active Input Handling 若是「Input System Package (New)」，uGUI 的 `StandaloneInputModule` 收不到事件。到 **Edit → Project Settings → Player → Active Input Handling** 设为 **Input Manager (Old)** 或 **Both**（本工程用的是旧输入，`Packages/manifest.json` 也没有 Input System 包，正常应是 Old）。

**音乐没声音**
`Synth` 在启动时合成音频（约 0.2–0.5 秒）。第一次运行会稍慢；之后正常。检查设置里 MUSIC/SOUND 是否被关掉。

**想替换成真实美术/音乐**
- 音乐/音效：把 clip 命名成 `music_bass / music_arp / music_lead / music_perc / engine_loop / sfx_click / sfx_whoosh / sfx_coin / sfx_combo / sfx_crash / sfx_lane / sfx_record / sfx_revive / sfx_buy`，放进 `Assets/Resources/Audio/`。
- 车辆/图标：改 `Assets/Scripts/Art/Art.cs`（全是 SDF 画法），或用真实 sprite 替换 `Art.Car()` 等函数返回值。
