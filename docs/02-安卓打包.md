# 02 · 打包 Android APK

> ⚠️ **先解决这个：你当前的 Unity 没有安装 Android 构建模块。**
> 我检查了 `C:\Program Files\Unity\Hub\Editor\6000.6.7f1\Editor\Data\PlaybackEngines`，里面只有 `WebGLSupport` 和 `windowsstandalonesupport`。没有 Android 模块就**无法导出 APK**，Build Settings 里 Android 平台会灰掉。

## 第 1 步：安装 Android 模块

Unity Hub → **Installs** → 找到 `6000.6.7f1` → 右侧齿轮 / 三个点 → **Add modules** → 勾选：

- ✅ **Android Build Support**
- ✅ **Android SDK & NDK Tools**（子项，必须勾）
- ✅ **OpenJDK**（子项，必须勾）

下载约 1.5–2 GB，装完后 `PlaybackEngines` 下会出现 `AndroidPlayer`。

## 第 2 步：切换平台

`File → Build Profiles`（旧版叫 Build Settings）→ 选 **Android** → **Switch Platform**。等资源重新导入。

## 第 3 步：确认工程设置

菜单 **EdgeRush → Apply Project Settings** 已经帮你设好这些，核对即可：

| 设置 | 值 | 位置 |
| --- | --- | --- |
| 包名 Application Identifier | `com.yourstudio.edgerush` ← **必须改成你自己的** | Player → Other Settings |
| 竖屏锁定 | Portrait（其余方向全关） | Player → Resolution and Presentation |
| 脚本后端 | IL2CPP | Player → Other Settings |
| 目标架构 | ARM64 | Player → Other Settings |
| 最低 API | Android 8.0 (API 26) | Player → Other Settings |
| 目标 API | Automatic (highest installed) | Player → Other Settings |
| 图形 API | OpenGLES3 | Player → Other Settings |
| 版本号 | bundleVersion 0.1.0 / code 1 | Player |

> TapTap 后台要求「包名不能带平台标识、versionCode 不能为 0」，并且**不接受 debug 签名的包**。

## 第 4 步：创建发布签名（只需一次）

用 Unity 自带的 JDK（装完 Android 模块后存在）：

```powershell
& "C:\Program Files\Unity\Hub\Editor\6000.6.7f1\Editor\Data\PlaybackEngines\AndroidPlayer\OpenJDK\bin\keytool.exe" `
  -genkeypair -v -keystore "C:\keys\edgerush.keystore" -alias edgerush `
  -keyalg RSA -keysize 2048 -validity 10000
```

记下密码，**keystore 文件 + 密码务必备份**（丢了就永远无法更新已上架的游戏）。

查 MD5（如果你以后要接 TapTap 登录，后台要填这个，注意去掉冒号）：

```powershell
& "...\OpenJDK\bin\keytool.exe" -list -v -keystore "C:\keys\edgerush.keystore" -alias edgerush
```

## 第 5 步：填写签名

`Player Settings → Publishing Settings`：

- ☑ Custom Keystore
- Keystore：`C:\keys\edgerush.keystore`
- Alias：`edgerush`
- 密码：你刚设的

## 第 6 步：出包

`File → Build Profiles` → Android → **Build**（不是 Build And Run），存成 `EdgeRush-0.1.0.apk`。

产物建议：`File → Build Profiles → 勾 Development Build 关掉`，用 **Release** 出包（默认非 Development 就是 release）。

## 第 7 步：真机安装

```powershell
# 手机开 USB 调试后
adb install -r EdgeRush-0.1.0.apk
```

没有 adb 时：把 APK 拷进手机，用文件管理器点开安装（需允许「安装未知来源应用」）。

## 体积与性能预算

- 预期 APK 体积：**25–40 MB**（IL2CPP ARM64 + 无素材；如果超过 50 MB，检查是否把 `Development Build` 勾上了，或加了多余包）。
- 目标 60 FPS：本工程同屏 sprite 数量 < 40，draw call 主要来自 UI，2 GB 内存的机器应该没问题。真机测试时用 **Window → Analysis → Profiler** 观察 GC：代码里已经避免了逐帧字符串分配的主要路径（分数/金币只在数值变化时更新）。

## 常见打包错误

| 错误 | 原因 / 解决 |
| --- | --- |
| `Android SDK not found` | 没装 `Android SDK & NDK Tools`，回第 1 步 |
| `Gradle build failed` / 许可证 | 首次 Gradle 下载依赖需联网；挂代理后重试 |
| `CommandInvokationFailure: Failed to re-package resources` | 通常是包名不合法（必须形如 `com.company.game`，只能字母数字下划线，段首不能数字） |
| 安装时报「应用未安装 / 签名冲突」 | 手机上已装过同包名但不同签名的版本，先卸载 |
| 启动黑屏 3 秒 | 正常：程序化生成美术 + 音频在启动时完成（见 `PrewarmArt`） |
