- Unity `6000.6.7f1`，Built-in 渲染；场景、uGUI、美术和音频由代码生成，没有引入大型框架或更换渲染管线。
- 三车道、点击左右半屏／横向滑动、0.12 秒变道、金币、擦边与 x1–x5 连击、暂停和复活流程。
- 四类障碍、图案库、三套道路主题。现有可解性检查仍是可达车道近似，完整时间窗和跨图案交通验证属于 C 批次。
- 七款外观：基础 Cyan、五款金币车与广告进度 Chrome Ghost；金币车保持现有 300–3000 价格，未扩至十款或给付费车改变操控／碰撞属性。
- 车库、签到、每日任务、设置、本地存档与本地统计事件。

## C 批次：公平与小规模内容

- 按真实车辆占用时间窗、长度、移动车轨迹和跨图案衔接验证交通路径；加入反应余量，保留固定种子复现。
- 新增独立磁铁与护盾模块，集中配置、对象池与状态展示；验证死亡与拾取同帧、护盾触发、保护结束、暂停冻结、复活清场。
- 保护穿过的障碍不计擦边；同一障碍不重复撞击或计分。
- 精修现有七款车的轮廓、尾部、克制尾迹与灯带；保持相同主体尺度、碰撞、变道和计分规则。
- 扩展减弱效果与低画质的粒子／拖尾预算，减少透明叠加；手感和交通可读性用实际试玩验证。

## D 批次：真实商业接入与测量

- 确定渠道、广告网络、主体、收款条件和稳定包名；TapTap-only＋AdMob 的完整收入路线尚未成立，支持商店及 readiness 另查。
- 安装并锁定最终 SDK，核对条件编译适配器，完成每次启动 UMP 更新、`CanRequestAds()`、隐私选项入口与测试设备设置。
- **处理合法的先关闭后奖励。** 当前守卫拒绝关闭后的后续奖励以隔离陈旧回调；聚合源可能合法乱序。最终 Provider 必须按 `showId` 保留可幂等提交的资格，并明确复活待决／补偿。当前 Mock 成功流程无法证明该场景。
- 完成可导出的匿名分析事件与安装／会话／事件／版本／UTC 标识；本地日志不等于运营数据。
- 曝光使用 SDK 曝光事件，收入使用 SDK paid 事件或后台按日对账；不以奖励次数伪造收入。
- 替换 `BuildInfo.PackageName`、`PrivacyPolicyUrl` 和其他正式信息，准备真实支持渠道与 SDK 清单。

接入说明见 `03-广告接入.md`；账号、素材、签名与发布门槛见 `04-TapTap-上架.md`。不再使用旧版固定 SDK 主版本、地区 eCPM、隐私豁免或固定年龄分级结论。

## E 批次：设备、小流量与发布

- 用不熟悉游戏的玩家观察教学、失败原因与再次开局；按成熟 cohort 统计留存，记录样本量与不确定性。
- 低档和中档 Android 设备检查触摸、刘海、系统返回、后台、断网、广告往返、升级和干净安装。
- 记录长局帧时间、持续 GC、内存、温度与冷启动；连续玩 20 分钟及反复进入车库／广告后确认没有持续增长。
