# 05 · 我做了什么 / 你需要做什么

## 一、我做完的（可直接运行）

### 核心玩法（文档第 3–6 节）
- 3 车道俯视公路，速度 8→22 单位/秒（每 10 秒 +1，140 秒到顶）。
- 操作：**点击左/右半屏** + **左右滑动** 双支持；换道 0.12 秒、ease-out、车身倾斜；**输入缓冲**（换道中再点会记住）；最外侧再点只震动不移动。
- 4 种障碍：普通车、卡车、路障、移动车（800 m 后出现，横向摆动并带琥珀色警示箭头）。
- 金币可收集。
- 碰撞盒比视觉小 10%（玩家）/12%（障碍），擦边不易误判。
- 难度：行间隔 1.6→0.55 秒（120 秒线性），前 15 秒热身（每行 1 个障碍），15/60/120 秒分段放开图案库。
- **图案库 27 个**，按难度 0–3 分级，每行最多 2 个障碍、至少留 1 条通路；**可解性自动检测**（`PatternLibrary.IsSolvable` 用可达车道集合模拟，不通过就退回单障碍）；高难度图案后强制插入简单图案作为呼吸口；同一图案不连续出现。

### 得分与连击（第 5 节）
- 距离：10 米 1 分；金币 +5；擦边 +10×当前倍数。
- 擦边判定：变道瞬间，被离开的车道上、前方 1.5 车长内有障碍 → 打标记；等它真正从身后过去且没撞 → 结算擦边。
- 倍数 x1–x5：每 3 次擦边 +1 级；5 秒无擦边后每 1.2 秒降 1 级（逐级衰减）；撞车清零；复活保留。
- HUD 显示倍数与到下一级的进度条。

### 状态机与复活（第 6 节）
- 启动 → 主界面 → 快速倒数（约 1 秒）→ 游戏中 → 暂停（继续时再倒数）→ 撞车演出（白闪/震屏/慢动作/碎片）→ 复活弹窗（5 秒倒计时）→ 结算。
- 每局最多复活 1 次；复活给 2 秒无敌（闪烁）、清空前方 26 单位障碍、速度回退到 80% 并在 3 秒内恢复、连击保留。
- **前 3 局不出复活广告**（按文档 7.3）。

### 界面（第 10 节，全部实现）
启动/主界面/游戏 HUD/暂停/复活/结算/车库/每日奖励/任务/设置，另加 Toast 与全屏闪光。全部代码构建，无需 prefab。

### 成长与留存（第 8 节）
- 金币、6 款付费车（300–3000）+ 1 款「看 5 次广告解锁」的 Chrome Ghost（带进度条）。
- 最高分、破纪录庆祝（金色闪光 + 音效）、「距离最高分还差 N 分」。
- 每日签到 7 天递增（50/75/100/150/200/300/500），断签重置。
- 每日 3 个任务（8 选 3，按日期确定性抽取，指标不重复），完成领金币。
- 本地存档：JSON + FNV 校验 + XOR 混淆，文件 + PlayerPrefs 双备份，损坏自动回退。

### 广告（第 7 节）
- `AdManager` + `IAdProvider` 抽象；4 个广告位；广告没准备好时按钮自动隐藏/禁用；失败静默；播放时全局静音。
- 编辑器里是 Mock 全屏广告（3 秒 + SKIP 模拟未完成）。
- AdMob 适配层已写好（`#if EDGERUSH_ADMOB`），换正式 ID 即可用。
- 频率：复活每局 1 次、双倍每局 1 次、每日广告 3 次/天、皮肤广告累计 5 次。

### 视听（第 9 节）
- 霓虹夜间风格：深蓝黑底、青色玩家车、暖色障碍、发光描边、暗角。
- **所有美术程序生成**：车（7 款外观含尾翼/条纹/光条差异）、卡车（2 种）路障、金币、图标、路面、车道线、速度线、路灯/隧道拱/沙漠岩石、星空、雾气、暗角。
- 速度感：路面 UV 滚动、两侧速度线、随速度拉远镜头、3 个主题每 500 m 渐变切换。
- 爽感：擦边 `CLOSE!/CRAZY!/UNREAL!/INSANE!`、0.09 秒慢动作、火花、震屏、金币飞散、倍数弹跳、破纪录闪光。
- **音乐音效 100% 合成**：4 层 stem（贝斯/琶音/主旋律/打击）随速度叠加，9 个音效 + 循环引擎声。可用 `Resources/Audio/` 里的同名文件覆盖。

### 数据与统计（第 11 节）
- 会话、开局/结算（分数/米数/时长/擦边/倍数/金币/是否复活）、广告展示/完成/失败/未就绪、皮肤解锁、签到、任务领取，全部本地记录并打日志，`Analytics.Summary()` 可随时导出计数。

### 工程化
- 自动配置：包名/竖屏/IL2CPP/ARM64/minSdk 26，自动建场景并加入 Build Settings。
- **离线编译验证**：`_tools/compilecheck.ps1` 用你本机 Unity 的引用程序集 + uGUI 源码，在没有编辑器许可证的情况下编译整个工程。当前 **0 error**（运行时 + 编辑器脚本都通过）。

### 关于隐私政策（最省事的做法）

1. 用 GitHub Pages：建仓库 → 加 `privacy.md` → Settings → Pages → 得到 `https://你的用户名.github.io/仓库名/privacy`。
2. 或 Notion 建公开页面 → Share to web → 复制链接。
3. 内容至少写清：收集什么（广告 ID、设备信息、崩溃日志）、为什么（广告投放/统计）、第三方（Google AdMob）、如何联系你、儿童条款。
4. 把链接填进 `Assets/Scripts/Core/BuildInfo.cs` 的 `PrivacyPolicyUrl`（设置页会用它）。

### 关于商店素材（我给了模板尺寸）

- 图标 512×512：用 `Art.Car()` 里的玩家车 + 霓虹背景做一张，程序生成后截图即可。
- 截图：真机跑起来后，用 `adb exec-out screencap -p > shot1.png` 截 5 张（开局、擦边瞬间、连击 x4、结算页、车库）。
- 封面 1920×1080：深色背景 + 大标题 + 车辆 + 「NEAR MISS RACER」。
- 视频：录 20 秒高光（连续擦边 + 破纪录），用手机自带录屏即可。

## 四、已知限制 / 风险

1. **启动 1–3 秒黑屏**：程序生成 ~40 张图和 4 层音乐。已做分帧预热，但首帧仍有一次集中开销。若真机上超过 3 秒，把 `GameApp.PrewarmArt()` 的范围再拆细，或改成异步线程生成纹理（需注意 Unity 主线程 API）。
2. **字体**：用 Unity 内置 `LegacyRuntime.ttf`（Arial 兼容）。要更好看的科技感字体，导入 TTF 到 `Resources` 并改 `Ui.InitFont()`。
3. **震动**：Android 需要 `android.permission.VIBRATE`。Unity 不会为 `Handheld.Vibrate` 自动加权限，代码里已 try/catch，**没有该权限时只是不震动，不会崩**。要真正生效：`Assets/Plugins/Android/` 放一份自定义 AndroidManifest（加 `<uses-permission android:name="android.permission.VIBRATE"/>`），或加一个构建后处理脚本。这一步我没做，因为手写完整 Manifest 风险高于收益。
4. **AdMob 适配层未真机验证**（没有 SDK、没有账号）。API 按 v9.x 写，若插件版本不同可能要对齐命名空间。
5. **Unity 6.6 较新**：如果你改用 Unity 6 LTS（6000.0.x），打开时 Unity 会提示升级工程，正常接受即可；`FindAnyObjectByType` 等 API 在 6000.0 也有。
